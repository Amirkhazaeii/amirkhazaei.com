# amirkhazaei.com

Personal research site. Static HTML + Three.js, no build step, hosted on GitHub Pages.

```
index.html               home: floating Voronoi field, one image cell per project (assets/js/voronoi.js)
publications.html        publications hub: papers/posters, ongoing and previous research
about.html               bio and contact
projects/<slug>/         one page per project, generated by tools/build.py
data/site.json           ALL content: profile, projects, publications
assets/js/scenes.js      Three.js hero scenes: sun | terrain | rollers | plankton
assets/img/<slug>/       images for each project (cover.jpg fills its home-page cell)
```

## Add a project

1. Make a folder `assets/img/<slug>/` with your images. `cover.jpg` (square, about 1200x1200)
   is what fills the project's cell on the home page.
2. Add an entry to `projects` in `data/site.json`. Copy an existing one; the fields are
   `slug, title, short, tagline, theme, status ("ongoing" | "completed"), year, period, role,
   weight, scene, cover, tags, summary, stats, sections, gallery, links`.
   `status: "completed"` moves it to "Previous research" in the hub. `weight` (about 1.0–1.3)
   makes its cell bigger. `scene` picks a 3D intro; leave it out to use the cover image.
3. Run `python tools/build.py` to create `projects/<slug>/index.html`.

The home page adds a cell automatically. Each project is an image-filled Voronoi cell; dark
cells tile the rest of the screen and shrink as more projects are added.

## Add a paper or poster

Add to `publications` in `data/site.json`:

```json
{ "title": "...", "authors": "Amir Hossein Khazaei, ...", "venue": "...", "year": 2026,
  "kind": "paper", "status": "published", "project": "<slug>",
  "links": [{ "label": "PDF", "url": "assets/papers/name.pdf" }] }
```

`kind`: paper | poster | talk | report | preprint. `status`: published | presented | review | preparation.

## Preview locally

```bash
python tools/serve.py 8933
```

Then open http://127.0.0.1:8933/ (this server disables caching, so edits show on reload).

## Publish (GitHub Pages + Namecheap)

1. Push this folder to a public GitHub repo. In the repo, open **Settings → Pages**, deploy from
   branch `main`, folder `/ (root)`, and set the custom domain to `amirkhazaei.com`. The `CNAME`
   file is already here.
2. In Namecheap, open **Advanced DNS** for amirkhazaei.com. Delete the parking records, then add
   four `A` records for host `@` → `185.199.108.153`, `185.199.109.153`, `185.199.110.153`,
   `185.199.111.153`, and a `CNAME` for host `www` → `Amirkhazaeii.github.io.`
3. When the DNS check passes, tick **Enforce HTTPS** in GitHub's Pages settings.
